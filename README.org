A video game guide for playing Shadow in the critically acclaimed raiding roguelike /Rabbit & Steel/.

** Export Process

The guide uses Emacs, Org-Mode, Org-Hugo and Hugo.

In a general gist, the workflow looks like:
1. Write up the guide in Emacs Org-Mode (.org)
2. Export to Hugo-compatible Markdown (org-hugo)
3. Hugo builds a static site of the Markdown files
4. Publish the site
